# HairGlow Camera — source-control recovery baseline

This repository was initialized on 2026-11-08 to preserve a reversible history for the already-live HairGlow public privacy/support site.

**Important:** Vercel project `hairglow-camera` is currently deployed from the Vercel CLI (`source=cli`), not from this Git repository. Creating files or pull requests here **does not update** `hairglow-camera.vercel.app` or the iOS/Android application. Do not connect Git, merge, publish or replace the current production deployment without separate approval and verification.

A separate Draft PR will stage a **text-only, exact-response snapshot** of the existing public Vercel legal/support pages; binary assets and app code are deliberately not claimed as recovered. The site's `/` currently serves the English Privacy Policy, which may be intentional for App Store legal URL usage; this is not treated as a defect without product-owner confirmation.

No deployment credentials, API keys or private data belong in this repository.
